Zpgraph

Interactive demos of the TypeScript charting library. Serve the package root (npx serve .) and open /demos/. Build first with npm run build.

  • Basic timeseries Legend, roller, animated zoom — the smoke chart.
  • Random dataset swap Button replaces the whole file with a new random series set.
  • Two y-axes Independent scales for small and large magnitudes.
  • Range selector Minimap under the plot with custom bars.
  • Dynamic update Append a live random point every second.
  • Annotations Static markers on peaks and valleys.
  • Highlight series Emphasize the hovered series; dim the rest.
  • Stacked + fill Stacked area chart with fill under the stack.
  • Error bars Value ± stddev bands.
  • Underlay bands Draw custom regions behind the series.
  • Synchronize Zoom and selection linked across two charts.
  • Crosshair Extra plugin drawing crosshairs on selection.
  • Per-series styles Stroke width, drawPoints, and fill toggled per series.
