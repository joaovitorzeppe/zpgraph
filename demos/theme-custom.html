Custom theme colors

Built-in theme: "dark" is a starting point. Override DOM chrome with CSS variables, and canvas chrome with option keys (user values win over the preset).

CSS variables

Warm amber chrome + lime / magenta series.

.zpgraph { --zp-legend-bg: #3b1d0f; --zp-legend-fg: #ffedd5; --zp-axis-label: #fdba74; } colors: ["#a3e635", "#e879f9"]

Options override

Violet chrome + gold / cyan series; custom grid/axis strokes.

theme: "dark", colors: ["#fbbf24", "#22d3ee"], gridLineColor: "#7c3aed", axisLineColor: "#a78bfa"
