Toolbar options

Default icons, text variant, i18n labels, custom SVG strings, and () => Node icons.

1 · Default icons

toolbar: true — SVG defaults, top-right.

2 · Text variant + PT labels

variant: "text" + labels / titles.

3 · Subset + top-left

tools + position: "top-left".

4 · Custom SVG / HTML strings

icons as SVG markup (or plain text).

5 · Custom DOM Nodes

icons: {"{"} pan: () => Node {"}"}.

6 · style / buttonStyle + dark

Inline style/buttonStyle, or CSS vars --zp-toolbar-*. theme: "dark" retints toolbar tokens.
